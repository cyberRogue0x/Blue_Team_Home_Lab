# Blue_Team_Home_Lab
# 🔐 Blue Team Cybersecurity Home Lab

A hands-on home lab project focused on defensive cybersecurity skills.

## 🧰 Tools Used
- VirtualBox
- Windows 10 / Server 2019
- Kali Linux
- Nessus
- Metasploitable
- Microsoft Excel
- Maltego
- Wireshark
- Nmap
- Splunk Enterprise

## 🧱 Lab Setup
- Host-only virtual network
- Logging is enabled on all VMs

## 📈 Skills Gained
- Vulnerability assessment
- Log analysis
